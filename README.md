# Coffee House — Landing Page

A responsive, two-page website for a modern coffee house, featuring adaptive layout and dynamic theme switching. Built as a part of the Fullstack Engineering course at **RS School**.

## 📸 Preview & Design Spec

The project is strictly developed according to the provided Figma design guidelines. It supports a full responsive range from desktop monitors down to mobile viewports (`1440px` – `380px`).

---

## 🛠️ Features Implemented (Part 1: Layout & Theme)

*   **Semantic HTML5 & Valid Layout:** Built using modern semantic tags (`<header>`, `<main>`, `<section>`, `<nav>`, `<footer>`) ensuring excellent accessibility and structure.
*   **Responsive Web Design:** Perfectly adapts across various screens using CSS Media Queries, Flexbox, and CSS Grid.
*   **Light & Dark Theme Switcher:** Smooth toggle between light and dark modes. The user's preference is saved in `localStorage` and persists upon page reload.
*   **Two Connected Pages:**
    *   `Home Page` — Includes 4 content sections (Hero, Favorite Coffee Slider, About/Our Story, Mobile App promo).
    *   `Menu Page` — Features a menu categorized by products (Coffee, Tea, Dessert) with responsive grids.

---

## 🧰 Tech Stack

*   **HTML5** (Semantic structure)
*   **CSS3 / SCSS** (BEM methodology, Flexbox, Grid, Custom Properties for themes)
*   **Vanilla JavaScript** (Theme switching logic, `localStorage` integration)
*   **Reset:** `modern-normalize`
